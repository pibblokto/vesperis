# Vesperis

A first-person, goal-less space exploration game, heavily inspired by
Alessandro Ghignola's *Noctis IV* (2001). Vesperis is vibe coded: the whole
thing was written with an AI coding agent, from the software renderer to the
planet function, in the space of a few days.

You fly a small ship between the stars of a procedurally generated galaxy,
approach planets and moons, pick a landing sector on a map and walk (or drive)
around on surfaces generated by the same function that painted the globe you
saw from orbit. Nothing has a name until you give it one. There is no
objective. Everything is deterministic: the same sector, star, planet and
square metre of ground is always the same.

The picture is rendered in software at 320x200 (scaled up 1x-4x) through
palette intensity ramps and a soft smoothing filter, in the spirit of the
original.

## Playing

Download the build for your machine from the
[releases page](https://github.com/pibblokto/vesperis/releases), unzip it and
run `vesperis` (on macOS, `Vesperis.app`). The game writes its save, settings
and guide files next to itself (the macOS app uses `~/Documents/vesperis`).

* **macOS**: the app is not signed. If it is refused, right-click it and choose
  *Open* once, or run `xattr -dr com.apple.quarantine Vesperis.app`.
* **Linux**: needs an X11 display (XWayland is fine) and OpenGL 3.3.
* **Windows**: a single `vesperis.exe`, no installer.

Press `H` at any time for the key reference, `Esc` for the menu.

## Building from source

Requirements: a C++17 compiler and [raylib](https://www.raylib.com) 5.x
(`brew install raylib` on macOS; on Linux install the `raylib` development
package or let CMake fetch it). Then:

```
make                # builds ./vesperis (the game) and ./vesperis_test (headless checks)
./vesperis
```

CMake works too: `cmake -B build-cmake && cmake --build build-cmake -j`. Add
`-DVESPERIS_FETCH_RAYLIB=ON` to download and build raylib when none is
installed (Linux, Windows), `-DVESPERIS_BUILD_GAME=OFF` to build only the
headless harness, and `ctest --test-dir build-cmake` runs the headless checks.
`packaging/make_app.sh` wraps the macOS binary into `dist/Vesperis.app`,
`packaging/make_zip.sh` makes a portable zip, `web/build_web.sh` targets the
browser with emsdk (experimental).

The headless harness needs no window: `./vesperis_test flow` plays through a
whole expedition and dumps frames to `shots/tests/`, `./vesperis_test unit`
runs the unit tests, `./vesperis_test regress` the determinism and frame
hashes; run it without arguments for the full list of modes.

## Controls

A gamepad works out of the box (left stick walks, right stick looks, A enter, B
back, X jump, Y data, bumpers sprint and chase view). Keyboard layouts: copy
`vesperis_keys.example.txt` to `vesperis_keys.txt` and list `PHYSICAL LOGICAL`
pairs, or use the key bindings screen in the settings.

In space:

| Key | Action |
| --- | --- |
| Mouse / arrows | Look around |
| `R` | Remote target: aim at a star, `Enter` or click to lock; `N` cycles the nearest stars |
| `V` | Vimana flight to the remote target (`V` again aborts) |
| `L` / click | Local target: next body, then the asteroid belts / the body under the crosshair |
| `Tab` | Solar system analyzer (bodies and belts; `Enter` approaches, `L` targets) |
| `Enter` | Fine approach to the local target |
| `X` | Center the view on the local target |
| `O` | Toggle orbit / fixed point chase |
| `F` | Field amplificator (brighter star field) |
| `G` / `M` / `J` | The GUIDE (name stars and worlds, notes, targets by name or coordinates, home, history, export/import) / star map / expedition log |
| `C` | Deploy the surface capsule (from orbit around a landable world) |
| `I` (`F2`) | Data sheet of the local target |
| `T` | Time warp x1 / x10 / x100 / x1000 / x10000 |
| `Ctrl+S` / `Ctrl+L` (`F5` / `F9`) | Save / load |
| `Ctrl+P` / `Ctrl+Shift+P` / `Ctrl+R` | Photo mode / panorama / frame recorder to `movies/` |
| `Ctrl+K` / `Ctrl+F` / `P` (`F10` / `F11` / `F12`) | Scanlines / fullscreen (also `Alt+Enter`) / screenshot (saved in `shots/`) |
| `H` (`F1`) | Help |
| `Esc` | Menu |

You live in the ship's cabin: the mouse turns your head, `W A S D` walk between
the windows, `E` uses what you face (the console on the left, the flight
computer at the front, the screens on the right, the capsule in its cage), `U`
lights the cabin, `Y` turns the hull to glass, `PgUp`/`PgDn` take the lifter to
the roof deck. The classic cockpit camera is one setting away (SHIP VIEW).

Landing map: arrows move the cursor (`Shift` = fast), `Z` zooms into the
cursor's sector, `R` picks a random lit land site, `C` toggles the cloud
overlay, `J` jumps under the biggest body in that world's sky, `Enter` lands,
`Esc` returns.

On the surface:

| Key | Action |
| --- | --- |
| Mouse | Look around |
| `W A S D` | Walk (`Shift` sprints, with stamina) |
| `Space` | Jump; held in the air, the jetpack thrusts |
| `1`-`9` / `0` | Autowalk speed presets / stop |
| `C` / `Z` | Crouch / stand tall (hold) |
| `Ctrl` | Dive while swimming |
| `B` | Unfold a buggy next to the capsule; `E` gets in and out; `W/S` drive, `A/D` steer, `Space` brake; `V` outside view |
| `M` | Set a waypoint on the spot under the crosshair, or clear it |
| `Q` / `E` | Board the capsule when standing next to it (return to orbit) |
| `K` | Call the capsule to your position |
| `N` | Sector map (2 km to 2048 km wide, `+`/`-` zoom, `M` places the waypoint); the sights you have found appear on it |
| `G` | The GUIDE: name the world or the nearest landmark, write a note |
| `V` | Vision modes |
| `X` | Highlight nearby creatures |
| `I` (`F2`) | Environment data sheet |
| `T` / `Ctrl+T` | Time warp / a 25 s time-lapse |
| `Ctrl+S` / `Ctrl+L` | Save / load |

The expedition is saved to `vesperis_save.txt` in the working directory when
you quit, and can be continued from the title screen. Names, notes and the log
live in `guide.txt`; settings in `vesperis_settings.txt`.

## Layout

```
src/core      math, hashing, noise, 8-bit framebuffer + palette + smoothing filter,
              scanline rasteriser with depth buffer, 5x7 font, PNG writer, input
src/galaxy    star field and star classes, system generator, the planet function,
              drainage, landmarks and maps
src/space     star field, suns, ray-traced globes and rings, sky bodies
src/surface   landing site geometry, terrain caches, sky, terrain, water, objects, life
src/game      state machine, autopilot, HUD, menus, save/load, audio synthesis
src/platform_raylib.cpp   window, input and audio via raylib
src/main_headless.cpp     tests and screenshot generation without a window
docs/         development notes: bug reports, plans, reference notes
```
