# The records' grammar: its files and rule prefixes

Generated by `vesperis_test grammar where md` from `src/peoples/grammar/` (`make check` holds it to the tree). The layout and the
rules are that folder's `CLAUDE.md`; a rule's place, its alternatives, what names it and what builds its name: `vesperis_test
grammar where <rule|prefix.*>`. A rule's prefix is its name before the first dot; `genre.<name>` is a genre, and a name without a
dot is a rule of its own (a word list: `crop`).
