# Reference notes

How the game works, one note a topic, each opening with its contents. Read the one you need; keep it true in the same change
as the code (edited in place, so it reads as now). The rules behind the code are in `../decisions/`.

1. `01-architecture.md`: modules, dependency rules, the frame's data flow.
2. `02-rendering.md`: framebuffer, palette banks, mush filter, rasteriser, banks per scene, draw order.
3. `03-coordinates-and-units.md`: axes, camera, body frames, local frames, sun position, units, constants.
4. `04-galaxy-and-systems.md`: star field, star classes, system generation, kinds of world, names.
5. `05-planet-function.md`: the shared planet function, LOD gating, feature fields, materials, planet maps.
6. `06-surface.md`: landing site, terrain caches, player physics, environment, lighting, objects, life, weather.
7. `07-game-flow-and-controls.md`: states, the ship, the landing map, the HUD, the save format, the audio state.
8. `08-testing-and-tools.md`: what each harness mode does and writes, at length.
9. `09-cookbook.md`: step-by-step recipes for common changes.
10. `10-decisions.md`: moved to `../decisions/` (a map of where).
11. `11-original-noctis-notes.md`: what the original did (from its source and manuals), what was replicated.
12. `12-civilisations.md`: split into `civilisations/` (a map of where): `peoples-and-ages.md`, `built-world.md`,
    `records-and-grammar.md`, `sound.md`, `radar.md`; `grammar-files.md` (the grammar's files by shelf and its rule prefixes,
    generated by `vesperis_test grammar where md`).

`harness/`: `INDEX.md` (every mode, one line each, generated by `vesperis_test help md`), `unit-checks.md` (the unit's checks
by group, generated by `tools/unitchecks.py`), `proof.md` (proving a change, and the proof tools). `lessons.md`: the lessons
behind the CLAUDE.md files' rules, by area.
