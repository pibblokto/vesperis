# Plans

* `ROADMAP.md` — milestones M0-M10 with actionable items (ids `Mx-NN`), sizes, dependencies and acceptance criteria. This is my proposal; edit freely or tell me what to reorder.
* `PLAN-movement-and-vehicles.md` (M8), `PLAN-generation.md` (M9) and `PLAN-look-hd.md` (M10) — detailed plans with the current-state analysis and the designs (the buggy, rivers, biomes, plates, the richer picture: resolution, textures, lighting, sky, with vibe guardrails and prototype sheets).
* `IDEAS.md` — unscheduled ideas, from cheap to wild. Promote to the roadmap by asking.
* `requests/` — your requests, one file each from `TEMPLATE-request.md`, named `R-NNN-short-title.md`.

Sizes: **S** under two hours, **M** about half a day, **L** one to two days, **XL** several days. They are estimates of focused work including verification through the headless tests.

Status values kept in each request and roadmap item: `proposed`, `accepted`, `in-progress`, `done (date)`, `rejected (reason)`.

How a request flows: you drop `R-NNN`, I answer inside the file (questions, approach, size), it gets an id in `ROADMAP.md` or a place in `IDEAS.md`, and the reference docs are updated when it ships.
